PowerShell 命令

这些命令没有在 Windows 上执行。Linux 上用对应的环境变量和 curl 核对过行为。

rustc --version
cargo install loco --version 1.3.1 --locked
loco new --name saas_app --db sqlite --bg async --assets serverside --os linux
Set-Location saas_app
$env:JWT_SECRET = "<standard-base64>"
$env:PORT = "43123"
$env:BINDING = "127.0.0.1"
cargo loco db migrate
cargo loco routes
cargo test
cargo loco start

要得到与公开树相同的文件，Windows 上必须写 --os linux。省略时默认是 windows，会多出 src/bin/tool.rs。本次没有编译那棵树。

预期：迁移日志出现 m20220101_000001_users；routes 含 9 个 /api/auth 路径以及 /_health、/_ping、/_readiness 和 GET /；start 监听所设端口。登录响应里的 token 不要记下来。
