PowerShell 命令

下面是运行这个公开仓库里的 saas_app。Windows 11 上没有执行过。Linux 上同一套迁移、测试和 HTTP 行为已经核对过。

git clone https://github.com/penanegrarenea-ship-it/loco-auth-course.git
Set-Location loco-auth-course\saas_app
# 可选。不设置时使用配置里的教学占位。不要把值打到屏幕上。
# $env:JWT_SECRET = "<standard-base64>"
$env:PORT = "43123"
$env:BINDING = "127.0.0.1"
cargo run --locked -- db migrate
cargo run --locked -- routes
cargo test --locked
cargo run --locked -- start

cargo install loco --version 1.3.1 --locked 只在要重新生成应用时需要。运行已有的 saas_app 目录不用再安装生成器。

config/development.yaml 里 mailer.stub 已是 true，进程不连接 SMTP。迁移会创建本目录下的 SQLite 文件，并应用 m20220101_000001_users。不要启动生产配置，不要填写真实邮箱账号。登录响应里的 token 不要记下来。

首页用的静态图不在公开源码提交里。需要时在仓库根目录手动运行 repro/restore-image.ps1。它会先核对 SHA256，再放入 saas_app\assets\static\image.png。应用启动不会自己下载。
