没测过的边界

  • Windows 编译、cargo test 和 PowerShell 实际执行。
  • --os windows 那棵树的编译。只比较过文件差。
  • 生产配置启动，以及任何真实 SMTP。
  • 重置令牌刚好 30 分钟、magic link 刚好 5 分钟。
  • stub 邮件的正文和链接格式。进程外读不到那封信，测试只断言封数，正文快照是注释掉的。
  • DownloadWorker 的任务执行。它被注册了，tests/workers/mod.rs 是空模块。
  • 框架里的 session 和 OAuth。生成的路由没有接上。
  • 把用户标成禁用后再登录。没有这个列，做不了这个实验。

已经测过的相反事实：未验证可以登录；过期重置返回 200 且不改密码；验证令牌没有过期；magic link 有域名限制；改密后旧 JWT 仍能读 current。
