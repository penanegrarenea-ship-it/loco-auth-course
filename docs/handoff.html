稍后打开 Pages

课程页已经在仓库的 docs/ 里。GitHub Pages 还没有打开。不要把任何主机名当成已经可用的学习地址。

所有者以后自己做的一次设置

  1. 打开仓库 Settings 里的 Pages。
  2. Build and deployment 的 Source 选 Deploy from a branch。
  3. Branch 选 main，文件夹选 /docs，保存。
  4. 用设置页当时显示的站点地址做检查。地址以那一页为准。

保存之后要看的四个地址

把 GitHub 显示的站点根记成 SITE。下面四个都应是 HTTP 200，而且页面能带上样式和脚本：

  • SITE/，正文里能看到课程标题。
  • SITE/lessons/05-login.html
  • SITE/assets/site.css
  • SITE/assets/site.js

在这四个结果出现之前，课程仍然只是 GitHub 上的文件：docs/index.html。离线时打开本目录的 index.html 即可。
