看这棵 saas_app 实际做了什么

给已经会生成 Loco 应用的人。每课先放代码或 HTTP 结果，再解释。不教安装，也不教一套新的 CRUD。

这些是普通 HTML。GitHub Pages 还没有打开，所以不要把某个网站地址当成已经可用。离线时直接打开本目录的 index.html。Rust API 仍要在本机用 cargo loco start 跑。开发配置里的 JWT 默认值是教学占位，不要用它部署后端。

所有者稍后打开 Pages 的步骤在 handoff.html。打开之后要用 GitHub 设置页显示的地址做检查，不要事先编造主机名。
