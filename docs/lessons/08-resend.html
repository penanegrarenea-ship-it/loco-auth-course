重发验证信的三种结果

三种邮箱，三种数据库结果，HTTP 都是 200。

结果

POST /api/auth/resend-verification-mail
未知邮箱                         200 null
已验证用户                       200 null，验证令牌仍是 NULL
未验证用户                       200 null，令牌换成新值

控制器 saas_app/src/controllers/auth.rs:230-259。

说明

未知邮箱直接返回，避免暴露邮箱是否存在。已验证用户不再发信，也不重写令牌。未验证用户再次调用 set_email_verification_sent，所以令牌列会变。这次只比较了前后是否不同，没有记录令牌值。

进程外读不到 stub 邮箱里的正文。封数由 cargo test 断言：未验证重发后是 2 封，已验证后再重发仍是 1 封。
