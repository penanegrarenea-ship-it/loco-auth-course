magic link 只收两个域名

域名、长度、五分钟、用过即删。

结果

POST /api/auth/magic-link
邮箱不以 @example.com 或 @gmail.com 结尾    400 invalid request
域名合法但没有这个用户                      200 {{}}
有这个用户                                  200 {{}}
令牌长度 32，magic_link_expiration 非空

GET /api/auth/magic-link/{{token}}
不存在                         401
未过期                         200，字段与登录相同，随后两列被清空
同一令牌再 GET                 401
过期列写成 2000-01-01          401，令牌列还在

域名正则 saas_app/src/controllers/auth.rs:16-19。请求 saas_app/src/controllers/auth.rs:181-205。兑换 saas_app/src/controllers/auth.rs:208-227。常量 saas_app/src/models/users.rs:10-11。

说明

成功请求返回的是空对象 {}，注册返回的是 null。这是 empty_json 和 json(()) 的差别。过期失败不会清掉令牌；兑换成功会先清掉再签发 JWT。没有测刚好 5 分钟。
