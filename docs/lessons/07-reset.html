过期重置仍返回 200

200 在这里不表示密码已经换掉。

结果

POST /api/auth/forgot  未知邮箱或已知邮箱都是 HTTP 200，正文 null
已知邮箱：reset_token 和 reset_sent_at 被写上

POST /api/auth/reset  错误 token：HTTP 200，旧密码仍能登录
把 reset_sent_at 改成 2000-01-01 再重置：HTTP 200
新密码登录 401，旧密码登录 200

未过期的重置：HTTP 200，两列清空，旧密码 401，新密码 200

忘记密码 saas_app/src/controllers/auth.rs:98-116。重置 saas_app/src/controllers/auth.rs:120-133。30 分钟判断 RESET_TOKEN_EXPIRATION_MIN 和 saas_app/src/models/users.rs:152-180。成功后清空 saas_app/src/models/users.rs:342-352。

说明

找不到或已过期都走进同一个分支，返回 JSON null，不改密码。调用方不能用状态码区分“换好了”和“令牌无效”。没有测刚好 30 分钟的边界，只测了明显过期。
