认证通过不等于授权

登录成功只证明你是这一个 pid。

结果

users 表没有 disabled、role、refresh_token
登录和 current 不读这些不存在的列
LoginResponse 没有 refresh 字段
改密、退出、按角色拒绝：这些路由不存在

框架源码里有 session store，可以按用户撤销会话。
生成出的 App::routes 没有接上那些路由。

列清单见 saas_app/migration/src/m20220101_000001_users.rs:10-34 和 repro/text/schema.txt。路由表 saas_app/src/controllers/auth.rs:261-273。

说明

认证回答“这个签名是不是这个 pid”。授权回答“这个 pid 能不能做这件事”。当前路由没有第二问。持有有效 JWT 就能读 /api/auth/current，没有角色可以挡。

api_key 会在插入时生成，但这些 HTTP 路由不用它登录。框架的 ApiToken 提取器没有接到生成的路由上。

这棵生成代码里，授权能力实际是？
