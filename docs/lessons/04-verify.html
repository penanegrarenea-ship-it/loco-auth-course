验证令牌没有过期

验证令牌会作废，但不会过期。

结果

把 email_verification_sent_at 改成 2000-01-01 后
GET /api/auth/verify/{{token}}
HTTP 200
null

同一 token 再 GET
HTTP 401
{{"error":"unauthorized","description":"You do not have permission to access this resource"}}

POST /api/auth/verify
HTTP 404，HTML，不是 JSON

查找只按令牌列等值匹配：saas_app/src/models/users.rs:96-109。成功后清空令牌：saas_app/src/models/users.rs:326-331。路由只有 GET：saas_app/src/controllers/auth.rs:77-91。

说明

email_verification_sent_at 被写下来，但查找函数不读它。所以把发送时间拨到 2000 年，原令牌仍然 200。用过之后列变成 NULL，再请求就是 401。

脚手架测试辅助函数向 POST /api/auth/verify 发 JSON。这条路由不存在，实测 404。真正生效的测试走 GET 路径参数。
