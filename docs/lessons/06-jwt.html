JWT 与 current

先看令牌里有什么，再看 current 查了什么。

结果

登录成功后解开的 JWT
header: typ=JWT, alg=HS512
claims: pid, exp
exp 与当时 unix 时间的差：604800 秒
没有额外 claim

GET /api/auth/current
缺 Authorization                         401
Bearer not-a-jwt                          401
签名段被改坏                              401
合法 Bearer                               200，字段 pid、name、email
删掉该用户后再用原 JWT                     404 not_found

签发 saas_app/src/models/users.rs:273-277。框架生成与校验 HS512、Base64 密钥、generate_token、validate。过期秒数 saas_app/config/development.yaml:115-115。

说明

current 的提取器是 auth::JWT，只校验签名和过期，不加载用户：src/controller/extractor/auth.rs:106-121。默认读 Authorization: Bearer。然后控制器自己 find_by_pid：saas_app/src/controllers/auth.rs:162-165。

secret 必须是标准 Base64。配置里的默认值是教学占位，不要拿去部署后端。用户已删除时，提取器仍然接受签名，控制器的查询变成 404，不是 401。
