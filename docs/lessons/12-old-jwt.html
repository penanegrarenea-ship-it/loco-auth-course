改密不使旧 JWT 失效

密码换了，签过名的 JWT 还在有效期内。

结果

1. 登录，留下 JWT，不把它写进任何公开记录
2. 完成一次未过期的密码重置
3. 旧密码登录变为 401，新密码登录为 200
4. 用第 1 步的 JWT 调用 GET /api/auth/current
   HTTP 200

JWT 校验只看签名、算法、过期和意外的 aud：src/auth/jwt.rs:217-248。没有 jti，用户表也没有吊销列表。

说明

reset_password 只换哈希并清空重置列。它不修改已经发出的 JWT，current 也不比较“令牌签发时的密码版本”。所以改密不能当作注销。

用户行被删掉是另一条路径：签名仍有效，但 find_by_pid 得到 404。那是行不在了，不是令牌被吊销。
