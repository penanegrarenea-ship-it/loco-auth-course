users 列以 SQLite 为准

迁移数组和实际表不是同一张清单。

结果

PRAGMA table_info(users) 的列序
created_at  timestamp_with_timezone_text  NOT NULL  DEFAULT CURRENT_TIMESTAMP
updated_at  timestamp_with_timezone_text  NOT NULL  DEFAULT CURRENT_TIMESTAMP
id          INTEGER                       NOT NULL  PRIMARY KEY AUTOINCREMENT
pid         uuid_text                     NOT NULL
email       varchar                       NOT NULL  UNIQUE
password    varchar                       NOT NULL
api_key     varchar                       NOT NULL  UNIQUE
name        varchar                       NOT NULL
其余令牌和时间列均可 NULL，且没有 UNIQUE

迁移手写列从 id 到 magic_link_expiration：saas_app/migration/src/m20220101_000001_users.rs:10-34。时间戳来自框架 create_table：src/schema.rs:490-496 和 src/schema.rs:24-38。

说明

唯一索引只有两条自动索引：email 和 api_key。pid 在插入时写成 UUID，表上没有 UNIQUE。没有 disabled、role、refresh_token 列。完整 pragma 在 repro/text/schema.txt。

Rust 实体把 id 写成 i64：saas_app/src/models/_entities/users.rs:11-12。文件头仍写着 sea-orm-codegen 1.0.0，lock 里的 sea-orm 是 2.0.4。以 PRAGMA 和实体字段为准。
