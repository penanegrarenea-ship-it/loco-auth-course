登录不要求已验证

注释和实测相反的地方就在这里。

结果

尚未验证，密码正确
POST /api/auth/login
HTTP 200
字段：is_verified=false，另外有 token、pid、name

验证之后，密码正确
HTTP 200
is_verified=true

密码错误，或邮箱不存在
HTTP 401
同一句 unauthorized 描述，没有原文 "Invalid credentials!"

登录函数 saas_app/src/controllers/auth.rs:137-159。它上面的注释 saas_app/src/controllers/auth.rs:74-75 写未验证不能登录。响应字段 saas_app/src/views/auth.rs:5-22。

说明

login 只查邮箱和 verify_password。不读 email_verified_at。is_verified 只是把该列是否有值放进 JSON。脚手架测试 can_login_without_verify 也期望 200。

401 外壳来自框架，不回显控制器里的字符串：src/controller/mod.rs:227-235。
